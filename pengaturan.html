KEAMANAN & PRIVASI

Keamanan Website

Halaman ini menjelaskan kondisi prototipe dan hal yang perlu disiapkan sebelum mengelola data nyata.

Belum produksi
!
Website saat ini merupakan situs statis

Belum ada autentikasi admin, backend, database, maupun penyimpanan formulir. Tombol dan formulir demo tidak memberikan perlindungan akun atau menyimpan data ke server.

✓
Data sensitif tidak dicantumkan sebagai contohJangan memasukkan NIK, nomor KK, alamat rinci, atau data pribadi ke halaman publik.
!
Login dan hak akses belum tersediaGunakan autentikasi server dan pembagian peran sebelum membuat area pengelola.
!
Formulir belum terhubung ke serverPengiriman pesan, aduan, dan layanan perlu endpoint aman, validasi server, serta kebijakan retensi.
!
Backup database belum tersediaBackup JSON hanya mencakup preferensi lokal browser, bukan konten atau database.
Sebelum produksi: siapkan backend, HTTPS, autentikasi kuat, otorisasi per peran, validasi input di server, pencatatan aktivitas, backup berkala, dan kebijakan privasi. Jangan menyimpan data kependudukan pada GitHub Pages publik.
